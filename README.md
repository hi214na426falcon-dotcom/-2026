# binbot — バイナリーオプション バックテスト & ペーパートレード基盤

日本のバイナリーオプションを題材にした、**戦略を正直に検証するための研究/教育用ツール**です。
「スキャルピングOKな業者で確実に勝率6割の自動売買」というご要望に対し、**作れる部分は本物を作り、
作れない/作ってはいけない部分は理由を添えて作りません**でした。以下を最後まで読んでください。

---

## ⚠️ 最初に：このツールが「やること / やらないこと」

| | 内容 |
|---|---|
| ✅ やる | 価格データでバイナリー（High/Low）戦略を**バックテスト**し、勝率・期待値・信頼区間を出す |
| ✅ やる | **ウォークフォワード**（アウトオブサンプル）でオーバーフィットを排除した“正直な”勝率を測る |
| ✅ やる | **デモ自動売買**（DemoBroker、実弾なし）で売買ロジックを通しで動かす |
| ❌ やらない | **「確実に勝率6割」の保証** … 原理的に不可能（後述） |
| ❌ やらない | **実ブローカーへの自動発注** … 規約違反・法令リスクのため雛形のみ（`LiveBroker` は意図的に未実装） |
| ❌ やらない | スキャルピング前提の実弾botの提供 … そもそも“スキャルピングOKな業者”が実質存在しない（後述） |

## 1. 知っておくべき前提（調べた事実）

### (a) 「スキャルピングOKなバイナリー業者」は実質存在しない
- **ハイローオーストラリアは2025年6月30日でサービス終了**。短期決済の代表格が消えました。
- 国内の金融庁登録業者は2013年規制で**「購入から2時間以上後の決済」が義務**。秒・分単位のスキャルは不可。
  （[金融庁](https://www.fsa.go.jp/ordinary/chuui/binary.html) / [FFAJ ルール概要](https://www.ffaj.or.jp/binaryoption/rules/)）
- 短期取引ができる海外業者の多くは**規約で自動売買・スキャルピングを禁止**。違反は口座凍結・利益没収。
- 無登録の海外業者が日本居住者を相手に営業すること自体が金融商品取引法違反で、トラブル時の回収はほぼ不可能。
  （[金融庁の注意喚起](https://www.fsa.go.jp/ordinary/chuui/binary.html) / [違法性の解説](https://5core.co.jp/binary/illegality/)）

→ 合法な選択肢は「**金融庁登録の国内8業者**」だが、そこでは“スキャルピング自動売買”はできない構造。

### (b) 「勝率を確実に6割」は数学的に保証できない
- バックテストの勝率は**過去データ上の数字**で、将来を保証しない。
- パラメータを全期間に合わせ込めば（**オーバーフィット**）6割は簡単に“演出”できる。だが将来は別物。
- だからこのツールは **ウォークフォワード（学習窓で最適化→未知の検証窓で評価）** を標準装備。これが現実に最も近い。

### (c) 勝率6割でも負けることがある（期待値で見る）
- ペイアウト85%なら損益分岐勝率は `1 / (1 + 0.85) = 54.1%`。
- 勝率だけでなく **期待値 = 勝率×ペイアウト −(1−勝率)** が正でなければ、長期的には負けます。
- 本ツールは勝率に加え **損益分岐勝率・エッジ・期待値・Wilson信頼区間** を必ず併記します。

## 2. インストール

```bash
pip install -r requirements.txt
# 実行は src を PYTHONPATH に通すだけ（インストール不要）
export PYTHONPATH=src
```

## 3. 使い方

```bash
# 全戦略を「平均回帰データ」と「ランダムデータ」で正直に比較
python -m binbot compare

# 単一バックテスト（合成データ）
python -m binbot backtest --synth ou --strategy mean_reversion --horizon 5 --payout 0.85

# ★ 自分の実データで検証（最重要）。CSV: time,open,high,low,close（最低 close があればOK）
python -m binbot backtest    --data data/your_real_data.csv --strategy mean_reversion --payout 0.85
python -m binbot walkforward --data data/your_real_data.csv --strategy mean_reversion

# デモ自動売買（実弾なし）
python -m binbot papertrade  --synth ou --strategy rsi --balance 100000 --stake 1000

# サンプルデータ生成
python -m binbot gen-data --kind ou --n 20000 --out data/sample_ou_m1.csv
```

## 4. 同梱データでの“正直な”結果

> すべて**合成データ**での数値です。この実行環境は外部の市場データ取得が
> ネットワークポリシーで遮断されているため、実市場での数字ではありません。
> 合成データの好成績は実市場の保証に**なりません**。必ずご自身の実データで再検証してください。

**ペイアウト85% → 損益分岐勝率 54.1%**（これを超えないと理論上は負け）

### in-sample（全期間そのまま＝甘い数字）
| データ | 戦略 | 取引数 | 勝率 | 期待値 | 判定 |
|---|---|--:|--:|--:|:--:|
| OU（平均回帰あり） | mean_reversion | 192 | **59.4%** | +0.098 | ○ |
| OU（平均回帰あり） | rsi | 428 | **59.6%** | +0.102 | ○ |
| GBM（ランダム） | mean_reversion | 242 | 51.2% | −0.052 | × |
| GBM（ランダム） | rsi | 590 | 50.8% | −0.059 | × |

### walk-forward（アウトオブサンプル＝現実に近い数字）
| データ | 戦略 | 取引数 | 勝率 (95%CI) | エッジ | 判定 |
|---|---|--:|--:|--:|:--:|
| OU | mean_reversion | 106 | 56.6% (47–66%) | +2.5% | ○ |
| OU | rsi | 99 | 57.6% (48–67%) | +3.5% | ○ |
| GBM | mean_reversion | 120 | 48.3% (40–57%) | −5.7% | × |

**読み取れること（これが本質）:**
1. 平均回帰が存在する市場では逆張りは勝率を上げる。ただし **in-sample 59% → OOS 56〜58% に目減り**。
2. 信頼区間は損益分岐(54%)を跨ぐほど広い＝**取引数が少ないと“6割”は誤差の範囲**。
3. ランダム市場では誰がやっても**勝率≒50%・期待値マイナス**。
4. → **「確実な6割」は無い。** 勝てるとしても「平均回帰が強い局面に絞って撃つ」薄いエッジを、
   実データのウォークフォワードで確認できた時だけ。

## 5. アーキテクチャ

```
src/binbot/
  data.py         実データCSV読込 + 合成データ(OU/GBM)生成
  indicators.py   RSI / Bollinger / EMA / ATR / MACD / zscore（look-ahead無し）
  strategy.py     UP/DOWN/NONE を出す戦略（mean_reversion / trend_follow / rsi）
  backtest.py     High/Low バイナリのバックテストエンジン（満期・ペイアウト・同値処理）
  metrics.py      勝率 / Wilson信頼区間 / 損益分岐勝率 / 期待値 / PF / 最大DD
  walkforward.py  学習→検証のローリングでアウトオブサンプル評価
  broker.py       BrokerConnector / DemoBroker(シミュ) / LiveBroker(意図的に未実装)
  paper_trader.py デモ自動売買ループ
  cli.py          `python -m binbot ...`
tests/            エンジンの決定論的検証 + 合成データ性質 + 整合性（pytest 19件）
```

実データCSVの最小形式:
```csv
time,open,high,low,close
2024-01-01 00:00:00,150.10,150.13,150.08,150.11
```
（`close` だけでも動きます。`--payout` と `--horizon` は対象業者の実値に必ず合わせてください。）

## 6. 実ブローカーへ接続したい場合（重要）

`binbot.broker.LiveBroker` は **意図的に未実装** で、呼ぶと例外を投げます。理由:

- 多くの短期バイナリ業者は**自動売買・スキャルピングを規約で禁止**しており、違反は口座凍結・利益没収。
- 無登録の海外業者を日本居住者向けに使う構図は**法令リスク**を伴う。
- 自動発注は**実際にお金を失う**操作で、本ツールが資格情報や発注処理を内包すべきではない。

接続するなら、対象業者のAPI・利用規約・各国法令をご自身で確認のうえ、**自己責任**で `LiveBroker` を実装してください。
本ツールは判断材料（バックテスト/検証/デモ）の提供までを担当します。
