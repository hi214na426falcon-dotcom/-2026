# LINEスタンプ制作キット（カワウソ＆柴犬）

毒舌・ゆるかわ系のLINEスタンプを、AI画像生成 → 背景透過 → Canvaで文字入れの流れで作るためのキットです。各キャラのプロンプトは実際に貼り付けて使える形で用意済みです。

- 🦦 カワウソのプロンプト集 → [`prompts/カワウソ.md`](prompts/カワウソ.md)
- 🐕 柴犬のプロンプト集 → [`prompts/柴犬.md`](prompts/柴犬.md)

---

## 全体フロー

1. **ベース生成**：各キャラの「ベースプロンプト」で1枚ずつ生成し、絵柄（顔・体型・色）を確定する。
2. **ポーズ展開**：確定したベース画像を**毎回、参照画像として添付**し、ポーズ別プロンプトを1つずつ実行する。
3. **仕上げ**：白背景で出力 → 背景を透過 → Canvaで文字入れ → 規定サイズで書き出し。

> **参照画像について**
> - 自分で生成したベース画像を参照させるのは問題なし。避けるべきは「他人の既存イラスト」の参照。
> - 参照画像を添付するときは、プロンプトの頭に日本語で
>   **「添付キャラの絵柄・体型・色を完全に維持したまま、次のポーズに変更して：」**
>   と一文足すと絵柄がブレにくくなります（本キットの各ポーズプロンプトには既に含めてあります）。
> - 文字は Canva で後入れするため、全プロンプトに `no text` を入れてあります。**各ポーズの見出しが、そのまま入れる文字**です。

## ⚠️ 先に決めること：個数

LINEスタンプの申請個数は **8 / 16 / 24 / 32 / 40個** のいずれかのみ。**30個では申請できません。**

| 案 | 個数 | 内容 |
|----|------|------|
| **案A（推奨）** | **32個** | 各キャラ 15種＋予備1種＝16種ずつ。予備2種は本キットに用意済み。 |
| 案B | 24個 | 各キャラ 12種に絞る。 |

本キットは **案A（32個）** をそのまま満たす構成です（カワウソ16種・柴犬16種）。案Bにする場合は、各キャラから使わない4種を外して12種ずつにしてください。

## 文字入れ・書き出し規格（Canva用）

### キャンバス設定

| 用途 | サイズ | 枚数・メモ |
|------|--------|-----------|
| スタンプ本体 | **370 × 320 px**（最大サイズ／幅・高さは偶数px） | 各1枚。キャラ＋文字は枠いっぱいに詰めず、**全周に約10pxの余白**を残す。 |
| メイン画像 | **240 × 240 px** | 1枚。ストアの顔になるので一番かわいいポーズを流用。 |
| トークルームタブ画像 | **96 × 74 px** | 1枚。顔アップを流用。 |

**形式**：背景透過PNG／RGB／**1ファイル 1MB以下**。

### フォント候補（Canvaで使える丸ゴシック系・商用OK）

- **M PLUS Rounded 1c**（太めウェイト推奨・一番スタンプっぽい）
- Kosugi Maru
- Zen Maru Gothic

### 文字入れのコツ

- 文字は**上端か下端に寄せ**、キャラの顔に重ねない。
- **濃い色の文字＋白フチ（縁取り）** にする → ダークモードのトーク背景でも読めるようにするため。
- 32枚全部で**フォント・サイズ・縁取りの太さを統一**する（審査でも見栄えでも有利）。

### 背景の透過

- Canva Proの「背景リムーバー」でOK（白背景のフラット絵なので綺麗に抜けます）。
- 無料で済ませるなら、LINE公式の「**LINEスタンプメーカー**」アプリの自動切り抜きでも可。
