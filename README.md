# デイピタアルファ EAスキャルピング & ウォークフォワードテスト一式

Nさん([NのEA開発ブログ / nmql.net](https://nmql.net/daypita123/))が配布する
EA「デイピタ」シリーズ(アルファ等)を検証・運用するためのリポジトリです。
**EA本体は含みません**(Nさんの配布物のため)。配布ページから入手したEAに、
ここの検証ツールを組み合わせて使います。

> **前提の確認(重要)**: デイピタは「サインツール」ではなく**完成済みのEA**です
> (デイピタ+はEURUSD M15のデイトレ型・マーチン倍率設定あり、と各種レビューで確認)。
> 「アルファ」の対象通貨・ロジック・対応プラットフォーム(MT4/MT5)は配布ページ
> https://nmql.net/daypita123/ で確認してください(この開発環境からは同サイトに
> アクセスできないため、最終確認はあなたのブラウザで)。

## 構成

| パス | 内容 |
|---|---|
| `walkforward/wfa_runner.py` | **メインツール**。MT4ストラテジーテスターを自動で回すウォークフォワードテスト・ランナー。任意のEA(デイピタアルファ本体を含む)に使える |
| `walkforward/wfa_config.json` | テスト期間・最適化パラメータなどの設定ファイル |
| `prompts/フォワードテスト運用プロンプト.md` | 毎サイクルClaudeに貼る分析・改修プロンプト集(プラン節約設計) |
| `docs/HFM口座ガイド.md` | どのHFM口座を開設すべきか(**デイピタは口座指定がある**ので必読) |
| `MQL4/Experts/DaypitaAlphaScalper.mq4` | (予備)サイン系インジケーターをEA化するラッパー。デイピタアルファがEAなら**不要**。別のサインツールをEA化したくなったとき用 |

## 全体フロー

```
[準備]
 1. https://nmql.net/daypita123/ でデイピタアルファの仕様を確認
    - 対応プラットフォーム(MT4/MT5)・対象通貨ペア・時間足
    - 入手条件(指定口座の開設が条件のはず → docs/HFM口座ガイド.md)
    - バックテスト(ストラテジーテスター)での動作可否
      ※無料配布EAは口座番号ロックがあり、テスターで動かない場合がある。
        その場合は本リポジトリのWFAは使えず、デモ口座フォワードのみで検証する
 2. 指定リンクからHFM口座を開設し、EA(ex4/ex5)を入手
 3. MT4のExpertsフォルダに配置

[検証ループ(ローカルPCで無料で回る部分)]
 4. wfa_config.json を編集:
    - "expert" をデイピタアルファのファイル名(拡張子なし)に
    - "symbol"/"period" を配布ページの指定に(例: EURUSD/M15)
    - "fixed_params"/"optimized_params" をEAの入力パラメータ名に合わせて書き換え
      (EAをチャートに刺してパラメータ名を正確に控える。ロット・マーチン倍率は
       固定にし、フィルター系だけ最適化するのが安全)
 5. python wfa_runner.py --dry-run で確認 → 本実行
    → IS(学習)最適化 → 最良パラメータでOOS(検証)テスト を全期間ぶん自動反復
 6. wfa_summary.csv を prompts/ のテンプレでClaudeに貼って分析 → 設定修正 → 5へ

[実運用への段階移行]
 7. WFA合格(目安: OOS勝ちウィンドウ60%以上・平均WFE 0.5以上)
    またはテスター不可の場合はデモ口座で1ヶ月以上フォワード
 8. 指定口座(HFMプレミアム等)で推奨資金・推奨ロットを守って本稼働
    ※デイピタ系はマーチン設定を持つため、推奨資金(50万円〜/0.01ロット目安)を
      下回る資金でロットを上げるのは厳禁
```

## プラン制限対策(重要)

- 計算負荷の高い「ループ」= バックテスト/最適化は **あなたのPC上のMT4が無料で実行**。
  Claudeのプランは一切消費しません。
- Claudeを使うのは **各サイクルの分析チェックポイントだけ**(CSV要約を1回貼る→回答1回)。
  常駐エージェントや定期実行は組みません(それがプランを一番消費するため)。
- 詳細は `prompts/フォワードテスト運用プロンプト.md` の冒頭ルールを参照。

## 動作要件

- Windows + MT4(HFM版でOK) / Python 3.9+(標準ライブラリのみ、pip不要)
