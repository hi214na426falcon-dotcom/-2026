# Whimo Web（非公式クローン / MVP）

SNSで見つけた「行きたいお店・スポット」を保存して、**地図**や**リスト**で管理・共有できるWebアプリです。
iOS向けの「Whimo（ウィモ）」がAndroidで使えないため、**リンクを知っていればブラウザで使える**Web版として作りました。

> ⚠️ 本家「Whimo」とは無関係の、個人開発のクローン（学習・実用目的のMVP）です。

## できること（現在のMVP）

- 📋 **リスト管理** … スポットをリスト（コレクション）単位で整理。複数リストの作成・切替・リネーム・削除。
- 📍 **スポット追加** … 名前・カテゴリー・メモ・場所・SNSリンクを保存。
- 🔗 **SNSリンク取り込み** … Instagram / TikTok / X / Google マップ / 食べログ 等のURLを貼ると、
  プラットフォームを自動判別してバッジ表示。カードから元の投稿にワンタップで戻れます。
- 🗺 **地図表示** … OpenStreetMap上にカテゴリー色分けピンで表示（Leaflet、APIキー不要）。
- 🔎 **場所の検索 / 地図タップで指定** … 店名・住所で検索（OpenStreetMap Nominatim）、または地図をタップして座標を指定。
- 🏷 **カテゴリー絞り込み** … カフェ / グルメ / スイーツ / 観光 / 自然 / ショッピング / 宿泊 / その他。
- ✅ **行った / 行きたい** … 訪問済みトグル。
- 📤 **リンクで共有** … リスト内容をURLに埋め込んで共有。**受け取った人はサーバー無しで取り込めます**（「リンクを知っていれば使える」）。
- 📱 **PWA対応** … Android Chrome等で「ホーム画面に追加」でアプリのように起動。オフラインでも起動可（地図タイルは要通信）。
- 💾 **保存** … データは端末のブラウザ（localStorage）に保存。

## 使い方（ローカル実行）

ES Modules と地図/検索APIを使うため、`file://` で直接開くのではなく **ローカルサーバー経由** で開いてください。

```bash
# このディレクトリで
python3 -m http.server 8000
# → ブラウザで http://localhost:8000 を開く
```

または Node がある場合:

```bash
npx serve .
```

## 公開（Androidで開けるようにする）

ビルド不要の静的サイトなので、そのままホスティングできます。

- **GitHub Pages**: リポジトリの Settings → Pages で、このブランチ/ルートを公開。発行されたURLをスマホで開くだけ。
- **Netlify / Vercel / Cloudflare Pages**: リポジトリを繋いでデプロイ（ビルドコマンド不要 / 出力はルート）。

公開URLをAndroidのChromeで開き、メニューから「ホーム画面に追加」でアプリ化できます。

## この版の設計判断（あとで変更可能）

| 項目 | 現在の選択 | 理由 / 次段階 |
|---|---|---|
| 配信 | ビルド不要の静的Webアプリ（Vanilla JS） | すぐ公開・軽量。将来React/Vite等へ移行も可 |
| 地図 | Leaflet + OpenStreetMap | APIキー不要・無料。要ならGoogle Mapsへ差し替え可 |
| 保存 | 端末内 localStorage | サーバー不要。**複数端末同期やアカウントは次段階（要バックエンド）** |
| 共有 | リスト内容をURLに埋め込み | サーバー無しで「リンク共有」が成立。件数が多いとURLが長くなる → 将来は短縮URL/DB化 |
| SNS取り込み | リンク保存＋自動判別（手動で詳細入力） | 投稿からの**場所自動抽出**はInstagram/TikTok APIやサーバーが必要 → 次段階 |

## ファイル構成

```
index.html            画面のマークアップ
styles.css            スタイル（モバイルファースト / ダークモード対応）
manifest.webmanifest  PWA設定
sw.js                 Service Worker（アプリシェルのキャッシュ）
icons/                アプリアイコン（SVG）
js/
  app.js              画面制御・イベント配線（エントリ）
  config.js           カテゴリー定義・プラットフォーム判定
  store.js            データモデル・localStorage永続化
  geo.js              住所検索・逆ジオコーディング（Nominatim）
  share.js            共有リンクのエンコード/デコード
  map.js              Leaflet地図の描画・ピック
```
