# デイピタアルファ EAスキャルピング化 & ウォークフォワードテスト一式

Nさんのサインツール「デイピタアルファ」をEA(自動売買)化してスキャルピング運用するための
リポジトリです。**インジケーター本体は含みません**(商用ツールのため)。手元にある
デイピタアルファの ex4/mq4 ファイルに、このEAを接続して使います。

## 構成

| パス | 内容 |
|---|---|
| `MQL4/Experts/DaypitaAlphaScalper.mq4` | サイン矢印を iCustom で読むスキャルピングEA本体 |
| `walkforward/wfa_runner.py` | MT4ストラテジーテスターを自動で回すウォークフォワードテスト・ランナー |
| `walkforward/wfa_config.json` | テスト期間・最適化パラメータなどの設定ファイル |
| `prompts/フォワードテスト運用プロンプト.md` | 毎サイクルClaudeに貼る分析・改修プロンプト集(プラン節約設計) |
| `docs/HFM口座ガイド.md` | HFMでどの口座を開設すべきかのガイド |

## 全体フロー

```
[準備]
 1. デイピタアルファの対応プラットフォームを確認(MT4想定)
    ※EA化・自動売買への利用が販売元の規約で許可されているか必ず確認
 2. HFMのデモ口座(MT4)を開設 → docs/HFM口座ガイド.md 参照
 3. デイピタアルファを MT4 の Indicators フォルダへ、
    DaypitaAlphaScalper.mq4 を Experts フォルダへ入れてコンパイル
 4. チャートにデイピタアルファを表示し「データウィンドウ」で
    買い矢印/売り矢印のバッファ番号を確認 → EAパラメータに設定
 5. MT4で対象通貨ペアのヒストリカルデータを取得(ツール→ヒストリーセンター)

[検証ループ(ローカルPCで無料で回る部分)]
 6. walkforward/wfa_config.json を自分の環境に合わせて編集
 7. python wfa_runner.py --dry-run で設定確認 → 本実行
    → IS(学習期間)最適化 → 最良パラメータで OOS(検証期間)テスト を全期間ぶん自動で繰り返す
 8. 出力された wfa_summary.csv を prompts/ のテンプレでClaudeに貼って分析
    → パラメータ範囲やフィルターを修正 → 7 に戻る

[実運用への段階移行]
 9. WFA合格(目安: OOS勝ちウィンドウ60%以上・平均WFE 0.5以上) → デモ口座でフォワード運用
10. デモ1ヶ月安定 → セント口座(少額実弾) → ゼロ口座(本番)
```

## プラン制限対策(重要)

- 計算負荷の高い「ループ」= バックテスト/最適化は **あなたのPC上のMT4が無料で実行** します。
  Claudeのプランは一切消費しません。
- Claudeを使うのは **各サイクルの分析チェックポイントだけ**(CSV要約を1回貼る→回答1回)。
  常駐エージェントや定期実行は組んでいません(それがプランを一番消費するため)。
- 詳細な節約ルールは `prompts/フォワードテスト運用プロンプト.md` の冒頭を参照。

## 動作要件

- Windows + MT4(HFM版でOK) / Python 3.9+(標準ライブラリのみ使用、pip不要)
