# フォワード/ウォークフォワードテスト運用プロンプト集

このファイルのプロンプトを **各サイクル1回だけ** Claudeに貼って回します。
重い計算(最適化・バックテスト)は全部ローカルのMT4がやるので、Claudeの消費は
「分析1回+改修1回」程度/サイクルに抑えられます。

## プラン制限に引っかからないための運用ルール

1. **エージェントの並列起動・常駐ループは使わない。** 1タスク=1会話=1プロンプト。
2. 長いレポートHTMLは貼らない。**wfa_summary.csv の中身だけ** 貼る(数十行で足りる)。
3. 会話を長く続けない。分析→回答をもらったら会話終了。次のサイクルは新しい会話で。
4. EAの改修依頼は「現象+期待動作」を1メッセージにまとめてから投げる(小出しにしない)。
5. 定期実行(Routine/cron)は設定しない。回すタイミングは自分でコントロールする。

---

## サイクル全体像(週1回程度を想定)

```
(ローカル・無料) python wfa_runner.py 実行 → wfa_summary.csv 生成
        ↓
(Claude・1回) プロンプトA で分析させる
        ↓
(ローカル) 提案どおり wfa_config.json / EAパラメータを修正
        ↓
必要ならプロンプトB(EA改修)を1回 → 再度ローカルで実行
        ↓
合格したらデモ口座フォワードへ → 週次でプロンプトC
```
