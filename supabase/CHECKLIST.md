# Supabase セットアップ & 動作確認チェックリスト

クラウド機能（アカウント／同期／共有／写真／家計簿の共有／旅のクラウド）を有効化して、
一つずつ動作確認するための手順です。所要 10〜15分。

## A. セットアップ

- [ ] 1. https://supabase.com にサインアップし、**New project** を作成（Region: **Tokyo (ap-northeast-1)** 推奨）。パスワードは控える。
- [ ] 2. 左メニュー **SQL Editor** → **New query** に `supabase/schema.sql` の中身を全部貼り付けて **Run**。
      「Success. No rows returned」なら成功（何度実行してもOK）。
- [ ] 3. 左メニュー **Storage** に `whimo` バケットができていることを確認（schema.sqlで自動作成）。
- [ ] 4. **Authentication → Sign In / Providers → Email** を有効化。
      テストを楽にするため、当面 **"Confirm email"（メール確認）を OFF**（本番前に戻す）。
- [ ] 5. **Project Settings → API** の値を `js/env.js` に貼る：
      - `SUPABASE_URL` = Project URL
      - `SUPABASE_ANON_KEY` = Project API keys の **anon public**
- [ ] 6. アプリをHTTPSで開く（GitHub Pages 等）。`file://` はGPS等が動きません。

## B. 動作確認

- [ ] 7. 左上 ☰ → 「ログイン / 新規登録」→ メール＋パスワードで**新規登録**。
      ヘッダーの状態が「クラウド同期中」になればOK。
- [ ] 8. リストにスポットを1件追加 → **別ブラウザ（またはシークレット窓）で同じアカウントにログイン**し、
      同じスポットが見えれば**同期OK**。
- [ ] 9. リストの「⋯」→「共有」→ **相手のメール**を追加。相手が同じメールでログインすると、
      そのリストが相手側にも表示される（一緒に編集できる）。
- [ ] 10. スポット編集 → 「📷 写真を追加」→ 再読み込みしても写真が残る（Storage保存）。
- [ ] 11. 📍ロゴを7回タップ/長押し → 家計簿。金額を「🔒自分だけ」で保存 →
      共有相手には**見えない**こと、「👫相手と共有」なら見えることを確認。
- [ ] 12. 「🧳 旅」→ ライブ記録 → ゴール → 旅詳細で「☁ クラウドに保存」→「👫 共有」。
      相手は「🧳 旅」→「☁ クラウドの旅」から**閲覧専用**でルート＋スライドショーを見られる。

## C. うまくいかない時

| 症状 | 原因 / 対処 |
|---|---|
| ログインしても「未ログイン」のまま | メール確認がON。手順4でOFFにするか、確認メールのリンクを開く |
| 「new row violates row-level security」 | schema.sql の実行漏れ。SQL Editorで再実行 |
| 写真が表示されない | `whimo` バケット未作成、または schema.sql のStorageポリシー未実行。再実行 |
| 共有相手に見えない | 相手が**招待したメールと同じアドレス**でログインしているか確認 |
| データを消したい | Supabaseの Table Editor / Storage から削除、または該当プロジェクトごと削除 |

うまくいかない箇所のエラーメッセージ（画面のトーストやブラウザのConsole）を貼ってくれれば、
こちらで原因を特定して直します。
