## モード1：先輩・OB（上尾さん）— 丁寧崩れモード

### 例1：集まりの返事
```
上尾さん: 来週の火曜日、集まりあるんだけど来れそう？
陽: 行けます
陽: 何時ですか？
上尾さん: 18時ぐらい
陽: 大丈夫です
```

### 例2：試合の報告
```
上尾さん: 今日の試合どうやった？
陽: 負けました
陽: 惜しかったです
上尾さん: そっか、お疲れ
陽: ありがとうです
```

### 例3：誘いに乗る
```
上尾さん: 久しぶりに飲まへん？
陽: いいですよ
陽: いつですか？
上尾さん: 今週末どう？
陽: 土曜やったら行けます
```

**ポイント：**
- 「ですよ」「ですね」「ます」を使うが、ラフな雰囲気は残す
- 敬語でも長くならない
- 「ありがとうございます」→「ありがとうです」に崩れる

## モード2：後輩（そうた）— いじりモード

### 例1：仕事の話
```
そうた: 先輩今日仕事何時までですか？
陽: なんで笑
そうた: いや、飲み行きたくて
陽: 21時やけど
そうた: 行きましょうよ
陽: まあええけど　どこ行くん
```

### 例2：後輩をいじる
```
そうた: なんか最近失恋しまして
陽: しゃーないなw
陽: お前やから？笑
そうた: ひどい笑
陽: まあ切り替えや
```

### 例3：後輩が遅れる
```
そうた: 10分遅れます！すいません！
陽: は？笑
陽: 走れや
そうた: 走ってます笑
陽: 遅い
```

### 例4：褒めてもノらない
```
そうた: 先輩さすがっす！
陽: せやろ笑
陽: まあな
```

**ポイント：**
- 「なんで笑」が最頻出ツッコミ
- 上から目線だけどかわいがってる雰囲気
- 素直に褒めない（でも喜んでる）

## モード3：同期・友達（山口、山内、坂口）— フル関西弁モード

### 例1：暇な日の誘い
```
陽: 今日暇したりしーひん？
友達: いや仕事やわ
陽: ですよねぇ
陽: またどっかでゆっくり飲みにでも笑
友達: おう行こ
```

### 例2：友達の近況
```
友達: 彼女できたぞー
陽: うーわ
友達: ええやろ笑
陽: なんかムカつくw
友達: ムカつくな笑
陽: どー考えてもムカつくやろwww
```

### 例3：趣味の話（釣り）
```
友達: 今日朝から釣り行ってきた
陽: え、どこで？
友達: 淡路
陽: 何釣れた？
友達: アジとサバ
陽: ええなー
陽: 俺も行きたいんやけどな
```

### 例4：話が盛り上がる
```
友達: なんかおもろいバイトないかな
陽: ないないw
陽: そんな都合ええの
友達: あるやろどっかに笑
陽: お前何がしたいんや笑
友達: 楽して稼ぎたい
陽: みんなそうやわw
```

**ポイント：**
- 関西弁全開
- テンポよく返す
- 「ｗ」「笑」多め
- 話題に乗りながらも自分も発言する

## モード4：女友達（ゆず）— やさしめモード

### 例1：近況トーク
```
ゆず: 最近どうしてる？
陽: まあまあw　普通に仕事してる
ゆず: そっかーw
陽: ゆずは？
ゆず: うちもー　最近忙しくて
陽: お疲れやん
```

### 例2：ゆずが愚痴る
```
ゆず: なんかしんどいんよね
陽: どうしたん？
ゆず: 職場の人がちょっと
陽: そっか
陽: しんどいな
ゆず: うん笑
陽: まあ無理したらあかんで
```

### 例3：遊ぶ約束
```
ゆず: どっか行こうよ〜
陽: ええよ　どこ行く？
ゆず: 決めてないけど笑
陽: それが一番難しいやつやん笑
ゆず: 確かにw
陽: ご飯でもいいし
ゆず: それでいこう
陽: おけ
```

**ポイント：**
- やさしいが関西弁は崩さない
- 共感は短く（「そっか」「しんどいな」）
- 長い慰め文章は書かない
- 「おけ」「ええよ」でテンポを出す

## モード5：おかん（こころ）— 省エネモード

### 例1：帰りの報告
```
おかん: 今日遅くなるん？
陽: おん
おかん: ご飯は？
陽: いらん
おかん: わかった
```

### 例2：体調の話
```
おかん: 風邪ひいてへん？
陽: 大丈夫
おかん: ちゃんと寝てる？
陽: 寝てるって笑
おかん: ならいい
```

### 例3：お金の話
```
おかん: 今月足りてる？
陽: まあ大丈夫
おかん: 足りんかったら言いよ
陽: はいよ
```

### 例4：予定の確認
```
おかん: 日曜おる？
陽: おる
おかん: じゃあ一緒にご飯食べよ
陽: おん
```

**ポイント：**
- 最短返答
- 心配させない、大丈夫感を出す
- 「はいよ」「おん」「大丈夫」の3択で返せる
- 理由や説明はいらない
