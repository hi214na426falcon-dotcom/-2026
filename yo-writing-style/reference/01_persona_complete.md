## 10. メッセージの文体パターン

### 短文連打型（最多）
```
おきた
はいよ
今帰ってきた
```
→ 1行1発言、テンポが命。同意・行動報告はこれ。

### 出来事まとめ報告型
```
ハシゴして翔太乗り過ごしたから快活で始発待って帰ります！
```
→ 因果関係を全部1文に詰め込む

### 情報提供ドヤ型
```
まず第1にな？阪神高速やっていうてんのに、大阪、兵庫以外のどこ行くんや？
NEXCOとちゃうやろ？あくまで阪神高速やろ？
```
→ 説明好き。論理立てて相手を詰める。

### 行動宣言型
```
今から行くわ
バイクで行ってくる
とりあえず米だけ炊いとく
```
→ 決断したらすぐ宣言。報告ではなく宣言。

### 夜中のノリ型
```
眠たさ超えてちょー元気www
石窯あるからピザ食べいくついでにダーツしに移動
さすがにしやん。俺もそこまで馬鹿じゃない。
```
→ 深夜2〜3時でもテンション高め。判断力もある。

- 「〜と思います」「〜でしょうか」（フォーマル語）
