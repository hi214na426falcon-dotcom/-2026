# 小村陽 note執筆 文体プロファイル

> **このファイルの使い方（Claude Codeへ）**
> note記事を書くときは、まずこのファイルを最初に読む。
> 次に `reference/` 内の4ファイルで「素の口調」の細部を確認する。
> このファイルが**上位ルール**。referenceと矛盾したら、必ずこのファイルを優先する。

---

## ⚠️ 最重要：声を2層で扱う

このプロファイルの肝はここ。雑に混ぜると失敗する。

| 層 | 何か | どこから来たか | noteでの役割 |
|---|---|---|---|
| **下層：素の指紋** | 関西弁・リズム・温度・価値観・笑いのツボ | `reference/` の4ファイル（LINE分析） | 文章の「血」。これが無いとAIの文になる |
| **上層：語りの翻訳** | 自分の物語を、ある程度の長さで読ませる呼吸 | 本人の殴り書き（後述のサンプル） | noteの「骨」。LINE短文を引き伸ばさないための型 |

### なぜ2層が必要か
`reference/` の4ファイルは全て **LINEの「会話モード」** の分析。
短く・テンポよく・1〜2文・いじり中心。これはLINEでは完璧だが、**note向けではない。**
noteは「語りモード」。自分の経験を、読者に読ませる長さで語る文章。

**やってはいけない失敗：** LINEの短文ノリをそのまま長文に引き伸ばすこと。
→ 「〜やんかw　〜やろw」を延々続けた不自然な文章になる。

**正しい配合：** 語りモードをベースにして、そこに素の指紋（関西弁・熱・リズム）を効かせる。
→ LINEの陽の「体温」を保ったまま、ちゃんと読ませる長文になる。

## 1. 物語の軸（全note を貫くテーマ）

**「プレーヤーでありながら、支える側に回ってきた人」**

商品（おにぎり）の説明から入らない。**この生き方から書く。**

### 軸を裏付ける実体験（ネタの幹）
- 中3でキャプテン。縦社会のキツさを知ってるからこそ「下の意見も吸い上げるチーム」を作ろうとした。
- 高3の花園。選手としてピッチに立てなかった。でも女子マネ不在の中、自分でテーピングを勉強し、ドローン分析で「みんなが同じ絵を見られるように」チームを支えた。サポートメンバーのトップに選ばれた。
- 卒業の年、男子全国2位・女子全国1位。その景色を「支える側」として味わった。
- バイクも自分で整備できるところまで覚えた。そこで出会った人と今も繋がってる。

→ 全部、同じ人がやってること。**「主役の隣で、主役を一番近くで支える」** ＝小村陽の個性。

### おにぎりキッチンカーの原体験（共感の起点）
- 選手時代、差し入れのおにぎりが **冷たく・パサついて喉を通らなかった。**
- 暑い中でも食べやすく、**低脂質・低カロリー・高タンパクで、すぐエネルギーになる**ものが欲しかった。
- それに特化した店がない。店舗は重いので、キッチンカーで始めたい。
- **「アスリートを、今度は飯で支える」** ── 支える側の生き方の、そのままの続き。

## 2. note語りモードの書き方ルール

### トーン
- **友達に話す距離感。** 「これやりたいんだよね」「これやり切ってきた」みたいな、近くて熱のあるトーン。
- 淡々・クールはNG。この人の魅力は熱量。
- ただし**暑苦しくはしない。** 感情は大げさに叫ばない（「最高！！！」みたいなのはLINEでもやらない人）。熱は内に込める。

### リズム（殴り書きから抽出）
- 体験を **畳みかけて**いく。短い節を「〜て、」「〜けど、」で繋いで流す。
- 区切りや感慨で **「かな」「かなって思ってます」** で締める。文末の「ね。」単体は使わない。
- 関西の口語が自然に混じる：「物足りひん」「しんどい」「〜やけど」「なんやろな」。
- 一段落の中で、勢いよく語ったあと、最後にふっと力を抜いて本音を置く。

### 文末・敬語
- **その時々で使い分ける。** タメ口・断定・です/ます を、内容の温度で切り替える。
- 読者に語りかける部分は柔らかい丁寧（「〜と思ってます」「〜なんですよね」）。
- 自分の決意や本音は言い切る（「やりたい」「これが俺」）。
- ガチガチの敬語（させていただきます系）はnoteでは使わない。それはLINEの上尾さんモード専用。

## 3. 素の指紋（reference から要点を抽出）

> 詳細は `reference/01〜04` に全部ある。ここはnoteで効かせる分だけ抜粋。

### note で活きる関西弁（混ぜすぎ注意・スパイス程度）
やから / やろ / やんか / 〜とる / 〜へん / できひん / ちゃう / おもて / ほな / そやな / しゃーない / えぐい / 物足りひん

### この人の温度を出すフレーズ
- 苦笑い・諦め：「しゃーないw」「まぁしゃーない」
- 納得：「なるほどな」「そやな」「まぁそれはそーか」
- 照れ隠し（本音を言ったあとに）：「まぁな」「知らんけど」
- 受け止め：「まぁ」「なんか」「とりあえず」（柔らかい前置き）

### 価値観（noteの説得力になる人柄）
- 計画より勢い（「弾丸で帰ろおもて」「とりあえず探す」）。でも要所は冷静（「しゃーないw」で流せる）。
- 後輩には厳しく見せて結局助ける。情が深いが表に出さない。
- 自分のことは自分でやる（バイク整備・テーピング独学）。覚えたことは身につける。

### noteでは封印するLINE専用要素
- 連続w・草・顔文字（ꉂ🤣𐤔 / (´・∀・｀)ʬ など）→ note本文では基本使わない。使うとしてもごく稀に「w」一個まで。
- いじり・煽り（「ぼけw」「しばくw」）→ 読者は後輩じゃない。使わない。
- 超短文連打（「はいよ」「おん」だけ）→ これは会話専用。語りでは使わない。
- 文末の「ね。」単体 → 気持ち悪く聞こえる。締めは「かな」「かなって思ってます」「なんですよね」などに替える。

## 4. 本人の語りサンプル（声の基準・最重要参照）

> Claude Codeへ：**これが「note語りモードの正解」。** referenceの会話例より、こっちを声の手本にする。
> 下記は本人が実際に口述した未編集の生テキスト。整えすぎず、この熱とリズムを保つこと。

### サンプルA：キッチンカーへの思い（要約・本人語り）
> アスリートとしてプレイヤーをやってたとき、おにぎりを差し入れでもらうけど冷たかったり、パサついて喉を通らない。暑い中でおにぎりは食べたいけどしんどい。食べやすいものがあればなと思ってた。おにぎりはお米が好きでええんやけど、なんか物足りひんかったりもした。アスリートとして、高タンパク高エネルギーっていうより、脂質が少なくてすぐエネルギー化されるもの、カロリーは低く高タンパクが求められてて、そういうのに特化した店がない。最初から店舗は重いから、コロナ禍で広がったキッチンカーを使って自分もやってみたい。ゆくゆくはガレージハウスみたいな大人の秘密基地を作って、昼はおにぎり屋、夜はバーで泊まれて、バイクでツーリングして、野菜の収穫体験もして、人とのつながりを作れる店にしたい。まずはキッチンカーでその経験を積みたい。ね。

### サンプルB：生い立ち（要約・本人語り）
> 小さい頃から人と違うことがしたかったわけやなくて、ただ料理が好きで、おままごとが好きで料理教室に通ってた。体操も水泳も好きで、個人メドレーで4種目泳げるようになった。中学から走るのも球技も嫌いやったのに、先輩に誘われてラグビーになぜかハマって、そこから中高大10年続けた。中3でキャプテンになって、縦社会がきついのはうざいから、上から下も仲良く、下からの意見も吸い上げられるチーム作りを目指した。高校は無名の中学から全国レベルのところへ行って、1年で18kg増やした。高3では選手として花園に立てんかったけど、女子マネがいない中でテーピングを勉強して、ドローンで「みんなが同じ絵を見れるように」分析して、サポートメンバーのトップに選ばれて、プレーヤーのサポートとして同じピッチに立った。最後は男子全国2位、女子全国1位っていうめちゃくちゃいい経験ができた。大学はバイクに乗りたくて強豪校には行かず、ガソスタでバイトして整備も覚えて、自分のバイクは自分でいじれるようになった。そこで出会った人らと今も繋がってる。半年留年もしたけど、最後の1年はめちゃくちゃいい経験になった。しんどい、やめたいって思いながらも、ラグビーできてよかったって経験が、今の自分に繋がってる。

**→ この2本のリズム（畳みかけ→「かな」「かなって思ってます」で締める／関西の素の口語）が note語りモードの基準。**
> ※ サンプルAの末尾「ね。」は口述の癖として残してあるが、**note本文では使わない**。

## 5. note配信の全体設計

- **構成**：無料 約10本 → 11本目以降 有料note。
- **狙い**：共感や経験をお金に変える（共感マネタイズ）。
- **無料10本の役割**：信頼の蓄積と「この人の続きが読みたい」を作る。
- **有料への転換点（11本目）**：何を売るかが収益を決める。物語の軸が効いてくる地点。
- **最重要要件**：**AI感を消す。** 読者に「小村陽が自分で書いてる」と感じさせる。

## 6. 執筆チェックリスト（書いたあと必ず確認）

- [ ] LINEの短文ノリを長文に引き伸ばしてないか（→語りモードになってるか）
- [ ] 連続w・顔文字・いじりが本文に紛れてないか
- [ ] 「支える側」の軸からブレてないか
- [ ] 畳みかけ→締めのリズムがあるか（平坦に説明してないか）
- [ ] 関西弁がスパイス程度か（出しすぎてないか）
- [ ] 感情を叫んでないか（熱は内に込めてるか）
- [ ] **読んだ友達が「これお前が書いたやろ」と言うか**（最終テスト）
