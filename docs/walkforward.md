# ウォークフォワードテストの手順（Mr.2 Gold）

Mr.2 Gold は暗号化された .ex4 で、MT4（Windows）のストラテジーテスターでしか動きません。
このため、次の分担で進めます。

1. **バックテスト**：あなたの PC の MT4 で実行し、レポートを保存する
2. **分析**：そのレポートを `backtest/analyze_mt4.py` に入れる（または Claude に渡す）
   - 次の項目を自動で計算します。
     - 最大ドローダウン
     - シャープレシオ
     - プロフィットファクター（PF）
     - ウォークフォワード
     - モンテカルロ
     - 推奨ロット

## 0. この EA でいう「ウォークフォワード」

通常のウォークフォワードは、次の手順で過剰最適化（カーブフィッティング）を見抜く方法です。

1. 過去の期間（IS：インサンプル）でパラメーターを最適化する
2. 続く未知の期間（OOS：アウトオブサンプル）で、そのパラメーターを試す
3. 1〜2 を期間をずらしながら繰り返す

Mr.2 Gold は、売買ロジックのパラメーターを変更できません。
自分で変えられるのは、ロット・マジックナンバー・**新規エントリー不可時間帯** だけです。そこで次の2つを行います。

| 分析 | 内容 |
|---|---|
| ローリング検証 | 期間を「IS 12か月 → OOS 3か月」で区切り、3か月ずつずらしながら全期間を評価する。<br>どの期間でも勝てているか（安定性）を確認する |
| 時間帯フィルターのWFA | IS で「新規エントリー不可時間帯（0〜4時間）」の最適値を選び、OOS に当てはめて効果があるか検証する。<br>本当の意味でのウォークフォワード |

**2つの期間** で分けて評価します。

| 区分 | 期間 | 目的 |
|---|---|---|
| (A) 5年 | 2021/10/01 〜 2026/09/30 | 長期の安定性。上昇相場・下落相場・高ボラ相場をすべて含む |
| (B) 一定期間 | 直近12か月（2025/10 〜 2026/09） | 現在の相場環境（金 $4,000〜5,600 の高ボラ）への適応 |

> **大事な注意**：EA の完成は 2026/02（v2.0 は 2026/04）です。それ以前の期間は、開発時に調整に使われた可能性が高い「事実上の IS」です。
> 本当の意味で未知の期間は、2026/04 以降とデモでのフォワードテストだけです。
> 5年バックテストの成績が良くても、それだけで安心しないでください。

## 1. ヒストリーデータを準備する（5年分の1分足）

HFM のサーバーから取得できる1分足は、直近の数か月分だけです。5年分は外部データを取り込みます。

1. 無料ツール **QuantDataManager**（StrategyQuant 社）などで、Dukascopy の XAUUSD 1分足（2021〜2026）をダウンロードする
   - MT4 用の .hst または CSV で出力します。
2. MT4 の「ツール → オプション → チャート」で、「ヒストリー内の最大バー数」と「チャートの最大バー数」を最大（9999999999）にする
3. 「ツール → ヒストリーセンター → XAUUSD → 1分足 → インポート」で取り込む
   - HFM のシンボル名が `XAUUSD` 以外の場合は、そのシンボルに入れてください。
4. **（推奨）Tick Data Suite（有料）を使う**
   - 実ティック・変動スプレッドで検証できるので、1分足スキャルピングの再現性が大きく上がります。

> MT4 標準のテスターは、1分足チャートの「全ティック」を、1分足データから作った疑似ティックで動かします。
> モデリング品質は 25% 程度になり、**スキャルピング EA の結果は実際より良く出やすい** です。
> スプレッドを厳しめにした検証を必ず併せて行ってください（手順2）。

## 2. ストラテジーテスターの設定

| 項目 | 設定 |
|---|---|
| エキスパートアドバイザ | Mr2_gold_v2.0(HFMonly) |
| 通貨ペア | XAUUSD |
| モデル | 全ティック |
| 期間（時間足） | M1 |
| スプレッド | **35**（HFM の実勢に近い値）。ストレステストで **60** も実行 |
| 期間を指定 | ✔（下の表の期間） |
| ビジュアルモード | オフ |
| エキスパート設定 → 初期証拠金 | 140000 JPY（実際の口座の通貨・金額） |
| パラメーター | 初期ロット 0.01、新規エントリー不可時間帯 false（基準テスト） |

- HFM の**デモ口座**でログインした MT4 で実行してください。v1.2 以降はデモ口座なら認証不要です。
- 金の価格は小数点以下2桁なので、1ポイント = $0.01 です。スプレッド 35 は $0.35 になります。

### 実行するテスト

| # | 期間 | スプレッド | 目的 |
|---|---|---|---|
| 1 | 2021/10/01〜2026/09/30 | 35 | (A) 5年の基準テスト |
| 2 | 2021/10/01〜2026/09/30 | 60 | (A) スプレッド拡大時の耐性 |
| 3 | 2025/10/01〜2026/09/30 | 35 | (B) 直近12か月（#1 から切り出して分析することもできます） |
| 4 | 2026/04/06〜現在 | 35 | v2.0 リリース後の真の OOS |

テスト後、「レポート」タブを右クリック →「レポートの保存」で `StrategyTester.htm` を保存します。ファイル名は例えば `mr2_5y_sp35.htm` にしてください。

### デモ口座でのフォワードテスト

テスターと並行して、デモ口座の M1 チャートで EA を 2〜4週間動かします。
終わったら、「口座履歴」タブを右クリック →「詳細レポートの保存」で `statement.htm` を保存します。
これが一番信頼できるデータです。

## 3. 分析ツールの実行

Python 3.10 以上が入った PC で、次のように実行します。

```bash
# 5年レポートを分析（IS 12か月 / OOS 3か月、直近12か月との比較つき）
python backtest/analyze_mt4.py mr2_5y_sp35.htm --capital 140000 --out report_5y.md

# デモのフォワード結果（詳細レポート）も同じように分析できます
python backtest/analyze_mt4.py statement.htm --capital 140000 --out report_forward.md
```

レポートのファイルを Claude に渡してもらえれば、分析と運用判断まで行います。

## 4. 指標の読み方

| 指標 | 意味 | 目安 |
|---|---|---|
| **最大ドローダウン（DD）** | 資産の山から谷までの最大の落ち込み | 資金の 20% 以内なら健全。30% 超は危険。50% 超は破綻予備軍。<br>バックテストの DD は実際より小さく出る前提で、**1.5〜2倍** を想定しておく |
| **含み損ベースの DD** | MT4 レポートの「最大ドローダウン」は、含み損を含む有効証拠金ベース | ナンピン型 EA では、決済済み残高ベースの DD より大幅に大きくなる。**こちらで判断する** |
| **プロフィットファクター（PF）** | 総利益 ÷ 総損失 | 1.0 未満は負け。1.0〜1.3 は優位性が薄い。1.3〜2.0 は良好。<br>2.5 超は過剰最適化を疑う |
| **シャープレシオ（年率）** | リターン ÷ リターンのブレ。値が大きいほど、安定して増えている | 0.5 未満は弱い。0.5〜1 は普通。1〜2 は良い。<br>3 超は「隠れたリスク（ナンピンの含み損など）」を疑う |
| **リカバリーファクター** | 純利益 ÷ 最大DD | 3 以上が目安 |
| **ウォークフォワード効率（WFE）** | OOS の年率リターン ÷ IS の年率リターン | 0.5 以上なら、未知の期間でも通用している |
| **モンテカルロ 99% DD** | 取引の順番を入れ替えて1万回試したときの、最悪クラスの DD | ロット計算にはこの値を使う |
