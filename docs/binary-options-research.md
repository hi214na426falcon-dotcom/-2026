## 0. 結論を先に（最重要）

1. **「勝率8割」は現実的な目標ではありません。** これは情報商材・自動売買ツール・
   一部ブローカー広告の常套句であり、継続的・再現的に達成された証拠はほぼありません。
2. 本当に見るべき数字は勝率そのものではなく、**ペイアウト率から決まる「損益分岐勝率」を
   どれだけ上回れるか（=エッジ）**です。
   - 損益分岐勝率 = `1 / ペイアウト率`
   - 例：ペイアウト 1.85 → **54.1%**、1.90 → **52.6%**、2.00 → **50.0%**
3. 現実に「優秀」と言える戦略でも、**アウトオブサンプル（未知データ）で 55〜58% 前後**出れば
   上等です。それでも長期では十分プラスになり得ます。逆に **バックテストで 70〜80% が出たら、
   まず過剰最適化（カーブフィッティング）を疑う**べきです。
4. ブローカー選び（特に海外無登録業者）のリスクは、戦略の優劣より大きい場合があります。

## 1. バイナリーオプションの仕組み

バイナリーオプション（BO）は、ある時点（**判定時刻 / 満期**）に、原資産（多くは為替＝
USD/JPY など）の価格が**エントリー時の価格（判定レート / 権利行使価格）より高いか安いか**を
予想する取引です。

- **High/Low（ハイロー）**: 満期に「上か下か」を当てる最も基本的な型。
- **Turbo / 短期（30秒〜5分）**: 海外業者に多い超短期型。後述するように、短時間ほど
  値動きは**ノイズ（ランダム）支配**になり、テクニカルの優位が出にくい。
- **Range / Touch**: 一定範囲に収まるか、特定価格に触れるか、などの派生型。

### 損益の構造

- 投資額（ペイ）を `S`、ペイアウト率を `P` 倍とする。
- **勝ち**: 払戻 `S × P`、純利益 `S × (P − 1)`
- **負け**: 投資額 `S` を全額失う（純損益 `−S`）
- **同値（判定レートが同一）**: 業者により「返却」または「負け」。本ツール既定は保守的に負け扱い。

この **「勝てば +(P−1)倍、負ければ −1倍」** という非対称性が、後述する損益分岐勝率を生みます。

### 国内規制型 BO と海外型 BO の違い（重要）

| 項目 | 国内（金融庁登録・金融先物取引業協会 FFAJ 加盟） | 海外（theoption / babaoption 等） |
|---|---|---|
| 最短満期 | 規制により実質**2時間程度以上**（超短期は不可） | **30秒〜数分**の超短期が中心 |
| 取引方式 | ラダー型・価格帯選択・スプレッド型など | 単純な High/Low が中心 |
| 規制・保護 | 国内法・分別管理・FFAJ 自主規制の対象 | **日本の金融庁に未登録の場合が多い**（後述） |
| 口座開設 | 本人確認・適合性確認が厳格 | 比較的容易 |

> 国内 BO と海外 BO は「名前は同じでも別物」です。ネット上の「勝率〇割」「必勝法」情報の
> 多くは海外の超短期型を前提にしており、超短期ほど優位を出すのは困難です。

## 2. 損益の数学 — ここだけは必ず理解する

### 2.1 期待値（EV）

1取引あたりの期待損益は、勝率を `w`、ペイアウトを `P`、投資額を `S` とすると：

```
EV = w × S(P − 1) + (1 − w) × (−S)
   = S × [ w·P − 1 ]
```

**EV > 0 となる条件**は `w·P − 1 > 0`、すなわち

```
w > 1 / P     ← これが「損益分岐勝率」
```

### 2.2 損益分岐勝率の早見表

| ペイアウト率 P | 損益分岐勝率 (1/P) | 「8割」勝てた場合の1取引EV（S=1000円） |
|---|---|---|
| 1.75 | 57.1% | +400円 |
| 1.80 | 55.6% | +440円 |
| **1.85** | **54.1%** | +480円 |
| 1.90 | 52.6% | +520円 |
| 1.95 | 51.3% | +560円 |
| 2.00 | 50.0% | +600円 |

- 仮に本当に勝率80%なら、ペイアウト1.85でも**1取引あたり +480円（投資額の48%）**という
  桁外れの利益率になります。**これが現実に持続するなら、世界中の資金が集まって即座に
  消えてしまう**水準です。「持続的に勝率8割」が眉唾である理由はここにあります。

### 2.3 連敗と破産確率

勝率55%でも、**連敗は普通に起きます**。独立試行なら「ちょうど k 連敗」する確率は
`(1−w)^k`。勝率55%（敗率45%）でも：

- 5連敗: 約 1.8%（数十回に1度は起きる）
- 8連敗: 約 0.17%（数百回やれば必ず遭遇）

固定額ベットでも連敗でドローダウンが膨らみ、**マーチンゲール（負けたら倍賭け）では破産が
ほぼ確定的に訪れます**（第7章）。

## 3. なぜ「勝率8割」は非現実的なのか

1. **市場の効率性とノイズ**: 為替の短期変動はランダムウォークに近く、特に数十秒〜数分の
   超短期では「方向の予測可能性」はごくわずか。本リポジトリの合成ランダムウォーク検証でも、
   どの定番戦略も勝率は50%付近に張り付き、ペイアウト<2.0では負け越します。
2. **取引コスト/判定の不利**: 実際にはスプレッドや約定タイミング、同値負けなどが
   不利に働き、見かけの勝率を押し下げます。
3. **過剰最適化（カーブフィッティング）**: 過去データに合わせてパラメータを探せば、
   いくらでも高勝率を「演出」できます。しかしそれは未来では再現しません
   （本ツールの「過剰最適化の実証」で体感できます）。
4. **小サンプルの錯覚**: 20〜30回で勝率8割が出ても、それは偶然の範囲。統計的に意味のある
   結論には**最低でも数百回**規模の独立した取引が必要です。
5. **生存者バイアス**: SNS で見える「勝ち報告」は、多数の負けた人が黙っているだけ、という
   選択効果。スクショや「実績」は容易に演出できます。

> **赤信号フレーズ**: 「勝率90%自動売買ツール」「必勝ロジック」「絶対に負けないサインツール」
> 「LINE登録で無料プレゼント」「元手◯万円が△百万円に」——これらは詐欺・情報商材の典型です。

## 4. ブローカーと規制のリスク（theoption / babaoption）

ご提示の2サイトはいずれも**海外（オフショア）運営の業者**で、**日本の金融庁（FSA）に
金融商品取引業者として登録されていない可能性が高い**です。国内で登録・FFAJ 加盟している
BO 業者はごく少数（国内 FX/BO 大手など）に限られます。

海外無登録業者を使う場合の現実的リスク：

- **出金トラブル**: 「出金条件未達」「本人確認不備」等を理由に出金が拒否・遅延する報告が多い。
- **投資者保護がない**: 国内の分別管理・苦情処理・紛争解決（ADR）の枠組み外。
- **税務**: 海外業者の損益は原則**総合課税（雑所得）**となり、国内 BO（申告分離20.315%）と
  扱いが異なる。確定申告の要否・区分を必ず確認すること。
- **規約変更・サーバー操作リスク**: 不利な約定やレート配信に対する第三者チェックが働きにくい。

**確認すべき公的情報**:
- 金融庁「**無登録で金融商品取引業を行う者の名称等について**」（警告リスト）
- 金融庁「免許・許可・登録等を受けている業者一覧」
- 一般社団法人 金融先物取引業協会（FFAJ）の会員一覧

> まず取引の巧拙より先に、**「その業者からちゃんとお金を引き出せるのか」**を確認してください。
> どれだけ勝っても出金できなければ意味がありません。

## 5. テクニカル戦略カタログ（バックテスト対象）

BO は「満期に方向が当たればよい」ので、**短期の方向性**を読む指標が使われます。本リポジトリの
ツールには代表的なものを実装済みです。

### 逆張り系（レンジ相場向き）
- **RSI 逆張り**（実装: `rsi`）: 売られすぎ(<30)→UP、買われすぎ(>70)→DOWN。レンジでは機能、
  強トレンドでは「逆張り即負け」になりやすい。
- **ボリンジャーバンド逆張り**（実装: `bollinger`）: ±2σ を超えたら反発を狙う。バンド拡大時は危険。
- **ストキャスティクス**（応用可）: RSI と同様の逆張り発想。

### 順張り系（トレンド相場向き）
- **移動平均クロス**（実装: `ma_cross`）: ゴールデン/デッドクロスで方向を取る。だましが多い。
- **MACD**（実装: `macd`）: ヒストグラムのゼロクロスで転換を取る。レンジでだまし多発。

### その他の発想（要自作）
- **サポート/レジスタンス・ライン**、**水平線/トレンドライン**でのタッチ反発。
- **ローソク足パターン**（ピンバー、包み足など）。
- **MTF（マルチタイムフレーム）分析**: 上位足のトレンド方向にのみ下位足で順張りエントリー。
- **経済指標時刻の回避**: 指標発表前後はノイズが激増するため、その時間帯を除外するフィルタは
  実務上効果が出やすい（＝勝てるからではなく「負けやすい局面を避ける」発想）。

> どの戦略も「万能」ではなく、**相場環境（トレンド/レンジ）に依存**します。重要なのは
> 「いつ使わないか（=見送る）」というフィルタ設計です。

## 6. 正しいバックテスト/検証の方法論

高勝率を“出す”ことは簡単ですが、**将来も通用するかを正しく検証する**のは難しい。以下は鉄則です。

1. **先読みバイアスの排除**: バー i の判断に、i より未来の情報を使わない。
   （本ツールは指標を終値 close[0..i] のみで計算し構造的に防止。）
2. **イン/アウトオブサンプル分割**: パラメータ調整は学習区間でのみ行い、検証区間（未知データ）で
   評価する。学習で良くても検証で崩れたら不採用。
3. **ウォークフォワード分析**: 期間をずらしながら「最適化→検証」を繰り返し、頑健性を見る。
4. **十分なサンプルサイズと有意性**: 数十回では偶然。勝率の **95%信頼区間**を見て、損益分岐勝率と
   統計的に区別できるかを確認する（本ツールは各結果に信頼区間と有意判定を表示）。
5. **取引コストを織り込む**: スプレッド・約定遅延・同値負け。コスト込みでプラスかを見る。
6. **多重検定（パラメータ漁り）の罠**: 100通り試せば、偶然に「勝てる設定」が見つかる。
   試行回数が増えるほど、見かけの好成績はあてにならない。
7. **データ品質**: 欠損・異常値・サマータイム・業者ごとのレート差に注意。
8. **フォワードテスト（デモ）で最終確認**: バックテストを通ったルールを、次章の手順でデモ運用し、
   ルールを変えずに一定回数こなして再現性を確認する。

## 7. デモ口座での「フォワードテスト」ステップ（自分で実施する手順）

> **バックテスト ≠ デモ取引**。デモ口座でできるのは過去検証ではなく、**リアルタイムの
> フォワードテスト**です。私（AI）が代わりにサイトへログインして取引することはしませんが、
> あなた自身が**規律をもって検証する手順**を以下に示します。

1. **ルールを先に文章で固定する**（後出しで変えない）:
   - 対象通貨ペア / 時間足 / 満期（例: USD/JPY, 5分足, 5分満期）
   - エントリー条件（例: RSI(14) < 30 で UP、> 70 で DOWN）
   - 取引しない時間帯（例: 重要指標の前後30分、early/late session）
   - 1取引の投資額は**固定**（資金の1〜2%以下を推奨）
2. **記録テンプレートを用意**（スプレッドシート）:
   日時 / 通貨 / 方向 / エントリー根拠 / 満期 / 結果(勝敗) / 損益 / メモ
3. **最低サンプル数を決める**: 結論を出す前に **100回以上**（できれば各環境で）こなす。
4. **途中でルール変更しない**: 連敗しても規律を守る。変えたらサンプルはリセット。
5. **集計**: 勝率・損益分岐勝率との差・最大連敗・ドローダウンを算出。
   本リポジトリのツールに**デモの取引ログ（CSV）を流し込めば**、信頼区間付きで評価できます
   （`--data` で読み込み、または手元で集計）。
6. **判定**: 勝率の95%信頼区間が損益分岐勝率を**明確に上回る**場合のみ「優位の可能性あり」。
   そうでなければ「誤差範囲＝優位は確認できず」。
7. **本番移行は慎重に**: デモで優位が確認できても、本番は心理・約定・出金リスクが加わる。
   最小ロットから。

## 8. 資金管理 — マーチンゲールは破滅への近道

- **固定額ベット（推奨の基本）**: 毎回同額。連敗時の損失が線形で読みやすい。
- **固定比率ベット**: 残高の一定割合（例1〜2%）。複利と保全のバランス。
- **マーチンゲール（厳禁）**: 負けるたびに倍賭けして「1勝で取り返す」手法。
  - 例: 1,000 → 2,000 → 4,000 → 8,000 → 16,000 …
  - **10連敗で必要額は 1,000×(2¹⁰−1)=約102万円**。連敗は勝率55%でも必ず訪れるため、
    資金上限・ベット上限に当たった瞬間に**大きな確定損失**となり、口座が飛ぶ。
  - 期待値がマイナスの賭けにマーチンゲールを重ねると、**破産確率が上がるだけ**で、
    EV は改善しない（むしろ悪化）。

## 11. まとめ

- 追うべきは「勝率8割」ではなく「**損益分岐勝率（1/ペイアウト）を統計的に上回るエッジ**」。
- 高勝率は**過剰最適化と小サンプルで簡単に演出**できる。検証(out-of-sample)で崩れたら無意味。
- **海外無登録業者の出金・保護リスク**は戦略以前の問題。公的な登録/警告情報を必ず確認。
- 資金管理は固定額/固定比率。**マーチンゲールは破滅**。
- まずは同梱ツールで「優位はそう簡単に出ない」現実を体感し、検証の作法を身につけること。
