# ロットと資金量の考え方（Mr.2 Gold）

前提（2026年10月中旬）: 金 約 $4,170、USDJPY 約 158.4、金の1日の値幅（ATR14）約 $50〜85。
HFM の XAUUSD は 1.00 ロット = 100 オンスなので、**0.01 ロット = 金が $1 動くと約 ¥158** の損益になります。

## 1. 販売元の基準

| 項目 | 値 |
|---|---|
| 初期ロット | 証拠金 **10万円あたり 0.01 ロット** |
| 最低証拠金 | 10万円 |
| 推奨証拠金 | 20万円 |
| 推奨レバレッジ | 1000倍 |

この基準で計算すると、0.02 ロットに必要な証拠金は **最低 20万円、推奨 40万円** です。

## 2. ロットごとの損益の大きさ

| ロット | 金 $1 の値動き | ATR $65（平均的な1日） | $100 の急変 |
|---|---|---|---|
| 0.01 | ¥158 | ¥10,300 | ¥15,800 |
| 0.02 | ¥317 | ¥20,600 | ¥31,700 |
| 0.03 | ¥475 | ¥30,900 | ¥47,500 |

## 3. 資金が30%減るまでの逆行幅

**合計保有量**とは、ナンピンなどで同時に持つポジションのロットを全部足したものです。
ナンピン型では、合計保有量が初期ロットの数倍になります。

| 資金 | 合計 0.01 | 合計 0.02 | 合計 0.05 | 合計 0.10 |
|---|---|---|---|---|
| 10万円 | $189 | $95 | $38 | $19 |
| **14万円** | **$265** | **$133** | **$53** | **$27** |
| 20万円 | $379 | $189 | $76 | $38 |
| 30万円 | $568 | $284 | $114 | $57 |
| 40万円 | $758 | $379 | $152 | $76 |

金は2026年に1日 $100 を超えて動く日が何度もありました（1月に $5,602 の最高値をつけた後、急落）。
**14万円・0.02ロットでナンピンが5本たまると、$27 の逆行で資金の30%を失います。**
これは平均的な1日の値幅の半分以下です。

## 4. ハイレバ口座のロスカットは「ほぼ全損」

レバレッジ1000倍では、1ポジションの証拠金は 0.01 ロットあたり約 ¥660 しかかかりません。
そのため、証拠金維持率が 20%（HFM の Premium 口座など）になってロスカットされる時点では、口座残高はほぼゼロです。
KATANA 口座のロスカット水準は 0% です。

つまり **ブローカーのロスカットは破綻防止になりません**。止めどころは自分で決めておく必要があります。

## 5. 推奨プラン

1. **デモ口座で 2〜4週間フォワードテストする**（v1.2 以降、デモ口座は認証不要）
   - 次の数字を記録します。後で `backtest/analyze_mt4.py` に詳細レポートを入れれば集計できます。
     - 最大保有ポジション数
     - 最大含み損（金額と資金比）
2. **本番は 14万円・0.01 ロットで開始する**
   - 販売元の最低基準（10万円で0.01）は上回っています。推奨基準（20万円で0.01）には届いていません。
   - 0.02 ロットは、販売元の最低基準で 20万円、推奨基準で 40万円が必要です。14万円での 0.02 ロットは基準を超えています。
3. **撤退ルールを先に決める**
   - 口座全体のドローダウンが **-25%（14万円なら -35,000円）** で一旦停止し、原因を確認する。
   - **-40%** で運用を中止する。
4. **ロットを上げる条件（両方を満たしたら）**
   - 口座残高が **30万円以上**（利益で増えた場合も含む）
   - 実績の最大含み損（0.01 ロットあたり）× 2 × 1.5（安全係数）が、資金の **30% 以内**
5. **利益が初期資金と同額まで増えたら、元本分を出金する**
   - 以後は利益だけで運用するので、破綻しても元本は残ります。

## 6. バックテスト結果から推奨ロットを計算する

`backtest/analyze_mt4.py` に MT4 のバックテストレポートを入れると、次の手順で推奨ロットを自動計算します。

```
推奨ロット = 資金 × 許容DD% ÷（0.01ロットあたりの最大DD【モンテカルロ99%点】× 安全係数）× 0.01
```

使い方は [walkforward.md](walkforward.md) を参照してください。
