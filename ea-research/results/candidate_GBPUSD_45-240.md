- egressポリシーで Yahoo Finance・Dukascopy・HistData など**FXデータ提供元は全て403拒否**。
  到達できるのは GitHub raw と各パッケージレジストリのみで、そこにFX実データは無い
  (GitHub上の"forexデータ"repoは軒並みダウンローダで、取得先が上記の遮断ホスト)。
- つまり README の決定的関門(直近2023-2025・別ソース)は、ここでは回せない。
  → それはユーザー提供データ or ブローカーでのデモフォワードでしか埋められない。

## 代わりに手持ちデータ(2012-2022)で"まぐれ vs 本物"を厳しく分解

| 検査 | 結果 | 読み |
|------|------|------|
| 方向分解 | ロング pf1.29 / ショート pf1.48 どちらも黒字 | 片方向レジームの偶然ではない(良) |
| 外れ値依存 | 勝ちtop10除去でも pf1.26 exp+7.96 | 数発の大当たり依存ではない(良) |
| 年次安定 | 11年中9年プラス。2015-2019が主柱(+11〜+25) | 単一イベント依存ではない(良) |
| **直近の減衰** | 2020 +8.5 → 2021 +5.1 → 2022 -13.5(n=5) | **エッジが年々細っている(懸念)** |
| ブートストラップ | 平均>0 の p=0.0054(単体では有意) | ただし下記の多重検定で相殺 |

## 決定的な留保(READMEの掟)
- **p=0.0054 は "74,000通り試した中の1つ" という多重検定を無視した値。**
  74,000回撃てば p<0.005 は偶然でも約370回出る。単体の有意性は"本物"の証明にならない。
- IN-SAMPLE分解が綺麗なのは"まぐれ"より良い兆候だが、**真の未見データを通るまでは候補どまり**。
- しかも OOS期(後半40%≈2019-2022)で減衰傾向。直近ほど弱い = 実運用で最も危ない形。

## 判定
- 74,304通りで唯一、自動裏取り＋手動分解を通った"最良"の候補。だが
  **「本物」ではなく「まだ棄却しきれていない1件」**。README基準では
  「別期間データ + デモ3ヶ月フォワード」を通って初めて"候補"。減衰兆候ゆえ優先度は中。
- リアル投入の判断材料としては不足。デモで様子を見るならロング/ショート両方・最小ロット。
