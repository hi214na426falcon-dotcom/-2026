## ⚠️ 最初に読む(これが一番大事)

このプロジェクトの目的は「勝つEAを見つける」ではなく
**「勝てない型を高速で捨て、まぐれと本物を見分ける」** こと。

### これまでの結論(実データ検証済み)
- 主要10通貨ペア(ゴールド含む)で **合計4,488通り** のシンプル指標EAを検証。
- 移動平均クロス / RSI逆張り / ボリンジャー逆張り / ブレイクアウト / 押し目 / 順張り。
- **out-of-sample(未来データ)で生き残った型はゼロ。**
- → シンプルな指標の組み合わせEAには、もうエッジ(優位性)が残っていない。
- → 世の無料EAの大半はこの「勝てない型」か、マーチンで一時的に隠しているだけ。

### カーブフィッティング警告(絶対に忘れるな)
組み合わせを増やせば「生存者」は必ず出る。それは勝てる型が見つかったのでなく、
**数を撃った結果のまぐれ当たりが統計的に紛れ込んだだけ** の可能性が高い。
ループで大量に回すほど、この偽物は増える。

**生存者が出ても喜ぶな。まず疑え。** 裏取りの手順は下記「生存者が出たら」を必ず実行。

## データについて
- ソース: GitHub `ejtraderLabs/historical-data`(無料公開)。
- 期間: おおむね 2012〜2022年頃の時間足(H1)。
- **弱点1**: 直近(2023〜2025)が薄い。生存者は必ず直近データで再検証。
- **弱点2**: 1ブローカーの1データソース。別ソースでの再現性確認が必須。
- 別時間足(m15等)が要るなら fetch_data.py の 'h1' を変えて要検証。

## 鉄の掟(core.py に強制済み)
1. 1エントリー=1ポジション。マーチン/ナンピン禁止。
2. 損切り固定。必ず入る。
3. スプレッド控除。盛らない(SPR_MAPはHFM保守値。実口座値に更新推奨)。
4. out-of-sample判定(前半6割で作り、後半4割で答え合わせ)。
5. 3分割 全区間プラス(まぐれ排除)。

## Claude Code での進め方

### 1. まず動作確認
```bash
cd engine
python3 -c "import core; print(core.backtest('trend',(20,50,14,20,40,20),'EURUSD'))"
```

### 2. ループを回す
```bash
python3 loop_template.py
```
※全格子×3分割検証は重い。この環境では時間制限に注意。
　Claude Code(ローカル)なら制限なく回せる。重ければ pair/logic を分割して回す。

### 3. 新しい型を試す(ここが本番)
`core.py` の `signal()` に新しいロジックを足し、`LOGICS` に名前を追加するだけ。
シンプル指標は全滅済みなので、次に試す価値がある階層:
- **複数時間足**: H1のトレンド方向にだけ、M15でエントリー(要 m15 データ取得)。
- **複合条件**: トレンド強度フィルタ(ADX等)+ 時間帯フィルタ(ロンドン/NY限定)。
- **ボラティリティ**: ATRベースの動的損切り・利確。
- 機械学習系は最後。過学習の温床なので検証を何倍も厳しく。

### 生存者が出たら(裏取り手順・省略禁止)
1. **別期間で再検証** — 直近2023〜2025のデータを別途入手し、そこで崩れないか。
2. **実スプレッドで再検証** — SPR_MAP をHFM実口座の実測値に上げる。
3. **デモ口座で3ヶ月フォワード** — ここを通って初めて「候補」。
4. リアル投入は最小ロットから。一括投入は絶対禁止。
