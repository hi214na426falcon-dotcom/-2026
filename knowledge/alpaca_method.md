## 2. 中核思想 🟢

複雑なインジケーターを多用するより、**価格そのものの流れ・位置関係・トレンド・ライン・時間軸**を重視する。

中心要素：価格 / 高値 / 安値 / トレンド / サポート / レジスタンス / トレンドライン / ベースライン / 短期逆行 / ノイズ / マルチタイムフレーム。

**基本フロー（上位→下位の順に絞り込む）**：

```
上位足 → 大局トレンド判断 → 高値・安値確認 → ライン確認
      → 短期足 → 短期逆行・ノイズ確認 → 継続 or 転換 → HIGH / LOW / 見送り
```

---

## 3. マルチタイムフレーム（MTF）🟢 + 定量化 🔵

- 原則：上位足と下位足を分けて考える。上位足=大局トレンド、下位足=エントリー精度。🟢
- 典型：5分足で大局 → 30秒足でタイミング。🟢
- 上位足が上昇なら、短期の下落は**押し目/ノイズ候補**。上位足が下降なら、短期の上昇は**戻り/ノイズ候補**。🟢
- ただし短期逆行が大きすぎればトレンド転換の可能性を考える。🟢
- 禁止：30秒足だけを見て「上がったからHIGH」と判断しない。🟢

**🔵 実装定義（MTF比率）**：下位足 N 本を1本に集約して上位足を合成する。
既定 `htf_ratio = 10`（例：30秒足×10 ≒ 5分足）。上位足のトレンドは §4 の定義で判定し、
下位足のシグナルを**ゲート**する（上位と逆方向のエントリーは減点/見送り）。

---

## 4. トレンド判定 🟢 + 定量化 🔵

**スイングの定義（🔵・因果的）**：`left=right=2` のフラクタルで、
ある足 j が「直近 left 本より高く、直後 right 本より高い」ならスイング高値。安値も対称。
※ スイングは `j + right` 本目で**確定**する。判定時点 i では `j + right <= i` の確定スイングのみ使用（未来を見ない）。

- **上昇トレンド** 🟢：高値切り上げ(HH) かつ 安値切り上げ(HL)。基本方向 HIGH。
- **下降トレンド** 🟢：高値切り下げ(LH) かつ 安値切り下げ(LL)。基本方向 LOW。
- **レンジ** 🟢：高値・安値更新が弱い/上下に振られる。基本方向 見送り寄り。

**🔵 トレンド強度 `trend_strength`（0〜3）**：直近スイングでの HH/HL（または LH/LL）連続数を数え、
`0=不明/レンジ, 1=弱, 2=普通, 3=強` にマップ。補助として `|baseline傾き| / ATR` を併用。

---

## 5. トレンドライン順張り 🟢 + 定量化 🔵

- 上昇：トレンドラインがサポートとして機能する所を探し、**ライン付近で反発確認 → HIGH候補**。🟢
- 下降：トレンドラインがレジスタンスとして機能する所で、**反落確認 → LOW候補**。🟢
- 「ラインに触れた＝即エントリー」ではない。価格反応・上位足方向・短期足状態を確認。🟢

**🔵 実装**：直近 `k=3` 個の確定スイング安値（上昇時）に線形回帰しトレンドラインを引く。
`|close - line| <= touch_atr × ATR`（既定 `touch_atr=0.5`）で「接触」、直後に順方向へ反発で「反発確認」。

---

## 6. ベースライン 🟢 + 定量化 🔵

- トレンドの軸となる基準線を意識。価格が大きく乖離したら「継続」と「回帰」の両方を考える。🟢
- 「乖離＝必ず反転」ではない。強いトレンドでは乖離したまま伸びることもある。🟢

**🔵 実装**：`baseline = EMA(period=20)`（対象足）。乖離 = `(close - baseline) / ATR`。
`|乖離| >= deviation_atr`（既定 `2.0`）を「大きく乖離」とみなし、回帰方向を**補助**シグナルにする（単独では入らない）。

---

## 7. ラインブレイク逆張り 🟢 + 定量化 🔵

- 重要ラインを**大きく**突破したら反転可能性を検討（HIGH急伸で上値ライン突破→LOW検討 等）。🟢
- 「ブレイク＝必ず反転」は禁止。強いトレンドでは継続もある。🟢

**🔵 実装**：直近サポレジ水準を `break_atr`（既定 `1.5`）×ATR 以上オーバーシュートしたら「過伸び」とみなし、
反転方向を**補助**シグナルに（強トレンド `trend_strength>=3` の間は減点して継続優先）。

---

## 8. 極・ライントレード（順張り＋逆張りの複合）🟢

1. トレンドライン確認 → 2. 価格が接近 → 3. 通常の反発なら順張り → 4. 大きく突破なら反転検討 → 5. 反応不明瞭なら見送り。
価格がラインの「どの位置」にいるかで判断を変える。🟢（=§5と§7を価格位置で切り替える統合ロジック）

---

## 9. ノイズ戦略（重要）🟢 + 定量化 🔵

短期足の細かな上下を、そのまま大局トレンドの変化と解釈しない。🟢

例：上位足=上昇 → 短期で一時下落 → サポート維持 → 再上昇 ⇒ 短期下落は**押し目/ノイズ** ⇒ HIGH候補。🟢
逆に、短期逆行が拡大し「安値切り下げ・サポート崩壊・上位足の構造変化」が出れば**転換候補**。🟢

**🔵 判定**：トレンド方向の直近スイングからの押し/戻り深さ `retrace = 逆行幅 / 直近スイング幅`。
- `retrace <= noise_max`（既定 `0.5`）かつ 上位足トレンド維持 → **ノイズ/押し目/戻り**
- `retrace > noise_max` または 直近スイングの Break of Structure（BOS）→ **転換候補**

## 10. HIGH / LOW / 見送り 🟢

**必ず3択を出せること。必ずHIGH/LOWを出す仕様は禁止。**🟢

### HIGH の主要因（🟢）
上位足上昇 / 高値・安値切り上げ / サポート機能 / 上昇TLで反発 / 短期下落後の反発 / 上位・短期の方向再一致 / ノイズと判断できる短期逆行

### LOW の主要因（🟢）
上位足下降 / 高値・安値切り下げ / レジスタンス機能 / 下降TLで反落 / 短期上昇後の反落 / 方向再一致 / ノイズと判断できる短期逆行

### 見送り要因（🟢）
トレンド不明 / レンジ中央 / ライン不明瞭 / 上位と短期が完全逆 / ブレイク直後で反応未確認 / 重要指標での急変リスク / **根拠が1つしかない** / 価格構造が崩壊

## 11. スコアリング（§10と整合）🔵

> 本人公表値ではない設計案。実データでバックテストして最適化する前提。

**HIGH 方向の加点**（LOW は各項の逆条件で減点）：

| 要因 | キー | 重み |
|---|---|---|
| 上位足が上昇 | `htf_trend_up` | +3 |
| 安値切り上げ(HL) | `higher_low` | +2 |
| サポート接触 | `support_touch` | +2 |
| トレンドライン反発 | `trendline_bounce` | +2 |
| 短期逆行後の反発（ノイズ確認） | `pullback_bounce` | +2 |
| 上位足と短期足が一致 | `mtf_aligned` | +2 |
| 強い上昇構造 | `strong_structure` | +2 |

**暫定判定しきい値**（`score` は HIGH加点 − LOW加点）：

| score | 判定 |
|---|---|
| ≥ +7 | **HIGH候補**（strong） |
| +4〜+6 | 弱いHIGH（既定は見送り／`allow_weak=true`でHIGH） |
| −3〜+3 | **見送り** |
| −6〜−4 | 弱いLOW（同上） |
| ≤ −7 | **LOW候補**（strong） |

**確信度 `confidence`（0〜100）** 🔵：`min(100, |score| / 13 × 100)`（13 = 満点）。
確率保証ではなく「AI内部評価の強さ」と説明する。

## 12. 資金管理 🟢 + 安全策 🔵

- **パーレー** 🟢：勝ったら次を増額（例 1000→2000→4000、負けで戻す）。勝率を上げる手法ではなく**ベット配分**。
- **マーチンゲール** 🟢：負けたら増額。連敗で必要資金が急増。**勝率向上手法として扱わない**。

**🔵 安全策（実装で強制）**：マーチンは既定で無効。使う場合も `max_steps`（既定3）と
資金比上限、ドローダウン警告を必須にする。無制限マーチンは実装しない。

---

## 13. ペイアウトと期待値 🟢

- 勝率だけでなくペイアウトを見る。損益分岐勝率 = `stake / (stake + payout)`。
- 例：ペイアウト80% → 損益分岐 ≒ 55.56%。
- 期待値 `EV = 勝率 × 勝ち利益 − 負け率 × 負け額`（手数料・約定・スリッページは別途）。
- AI は「勝率60%」だけで判断せず**ペイアウト込みの期待値**で評価する。🟢

## 14. 口座・業者リスク 🟢

エントリー精度 / 勝率 / ペイアウト / 資金管理 / 業者規約 / 取引制限 / 口座凍結リスク を**別々に**扱う。
「勝てる手法」でも「自由に大金を取引できる」とは限らない。**多くのブラウザ型業者は自動売買を規約で禁止**。

## 15. 分析順序 🟢

相場環境 → 上位足 → トレンド → 高値安値 → サポレジ → トレンドライン → 現在価格の位置 → 下位足 → ノイズ → 転換可能性 → エントリー方向 → 見送り条件。

「どちらに賭けるか」より「**なぜその場所で判断するか**」を重視する。🟢
